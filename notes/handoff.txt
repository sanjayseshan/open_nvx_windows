## Performance plan (nine steps)

1. **Reduce push-buffer memory-write cost and measure it.** Use matching write-combined aliases for the MDL-backed GART buffer and record time spent copying the command stream. **Implemented for 4.0.0.27; hardware result pending.**
2. **Remove the extra GM107+ VBO serialize/memory-barrier patch.** Keep Nouveau's upstream NVC0 barrier logic and verify image correctness. **Removed from the active Mesa 25 patch series for .27; patch file retained as historical reference.**
3. **Decouple Nine submission/presentation from the app thread.** Enable Nine threaded swapchain submission. CSMT remains guarded by `buffer_map_persistent_coherent`; NVC0 does not advertise that capability, so do not force multi-context CSMT until persistent-map coherency and shared-winsys concurrency are proven. **Threaded submit enabled for .27; CSMT investigation remains open.**
4. **Increase work per escape.** Trace flush/kick causes and coalesce compatible push-buffer batches while preserving ordering and fence semantics.
5. **Reduce repeated kernel validation cost.** Profile packet/address validation by method; cache only immutable per-client allocation metadata and retain validation of submitted command streams.
6. **Reduce buffer lookup cost.** Replace repeated linear scans with a bounded client/GPU-VA lookup structure if profile samples show lookup is material.
7. **Shorten global critical sections.** Measure lock hold/wait time, then move parsing/copying outside locks where ownership rules allow.
8. **Keep completion asynchronous.** Retire BOs through fences and avoid CPU waits on ordinary submits; wait only for explicit readback, reuse, or teardown dependencies.
9. **Separate diagnostic overhead from workload cost.** Compare quiet and diagnostic runs, retain failure-only logging, and report CPU submit, fence wait, GPU execution, and frame time separately.

## 4.0.0.27 changes and test

- Kernel GART backing now requests `MmWriteCombined` for its system alias, matching `NvxMdlMapUser`; this replaces the prior conflicting NC/WC aliases. A per-submit TSC counter records command-copy cycles alongside IOCTL and validation counters.
- The external `0010-nvc0-gm107-vbo-dirty-barrier.patch` is no longer applied by `test/mesa25_patch_series.txt`; Mesa's upstream NVC0 logic remains authoritative.
- Nine's `thread_submit` is enabled. Nine CSMT is still disabled by the upstream capability gate because NVC0 does not advertise persistent coherent buffer mapping. Do not claim CSMT is active unless the guest log proves it.
