## Changes in this iteration

- `src_win98/winvbe_drv/vbe.c`: allocate and configure a replacement LFB selector set before releasing the old one. A failed larger-mode mapping no longer discards the previous usable framebuffer selectors.
- `src_win98/winvbe_drv/enable.c`: ReEnable now refuses VGA mode 13h fallback. If requested native mode fails, it restores the prior mode bookkeeping, keeps the previous scanout, and returns failure to GDI. Initial Enable retains its VGA fallback.
- `src_win98/shim/videoprt_shim.c`: native mode request guards now report why the request was rejected.
- `src_driver/nvx_disp_rpc.c`: primary scanout logs the failing DMA setup, channel reservation, flush, head emission, or notifier stage.
- `test/update_win98_driver.sh` installs `GpuCopy=1` and `Debug=0` by default. The current 3DMark-first run bypasses the regular GDI/WGL suite, so smooth window-copy behavior still needs a regular-suite check.
